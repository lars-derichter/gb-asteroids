# Aan de slag

Installeer GB Studio en open een sample project om rond te kijken.

---

## Installatie

- Download en installeer de versie van GB Studio voor jouw besturingssysteem: [chrismaltby.itch.io/gb-studio](https://chrismaltby.itch.io/gb-studio)
- Deze versie van de tutorial is gemaakt met v4.3.2; alle 4.x versies werken
- Je vindt de tussenversies als zip-bestanden in de map versions

---

## Sample project

- Open GB Studio
- Kies **New**
- Verwijs bij Path naar je Desktop (of een andere makkelijke locatie)
- Project name: sample
- Template: het kleurrijke sample project
- **Create project**
